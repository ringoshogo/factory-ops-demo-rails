# サイクル 06 の振り返り

サイクル 06（M42・M43・M44・M45・M46・M41 の残り）の計画が実装にどれだけ合っていたかと、回し方そのものが働いたかを評価した記録である。手順は `guides/cycle-end.md`「1. 振り返り」にある。ここで挙げた想定外は、知見の収穫（`harvest.md`）と再発防止（`recurrence.md`）の入力になる。

読んだものは、計画レビューの証跡（`plan-review.md`）、実装レビューの証跡（`implementation-reviews.md`）、サイクルの commit の履歴（`052a8c1..1358e37`）、計画の節を直した commit、台帳 2 本、PR #73〜#81 と Dependabot の PR の状態、M42 をマージした後の main への push の CI の記録である。取りまとめ役が担当とレビュアーを動かしたときと、作者に判断を問うたときに見たこと（担当への伝言、作者への説明、レビュアーの終わり方）は、リポジトリに残らないので、ここに書いた。

## サイクルの途中で範囲が変わったこと

サイクル 06 は、計画レビューの時点では M42・M43・M44 と、サイクル 05 から移した M33・M41 の残りの 5 つだった。作者は M44 を終えた後に、作者を待つ行のうち OI-144（並べ替えの列を一覧の表に限るか）の既定を変え、流用元の画面が並べる値での並べ替えと、在庫の品目の検索と、複数の列での並べ替えを、すべてサーバーで作ると決めた。OI-178・OI-179・OI-181 にも答えた。取りまとめ役は、OI-144 と OI-179 の答えが API に及ぶので、M45〜M47 を起こして差分の計画レビューに通し（`plan-review.md`「M45〜M47 と、M33 の残りの差分」）、サイクルの上限の 6 つに収めるために、M47 と M33 の残りをサイクル 07 へ置いた。

M41 の残りは、作者の判断がすべて決まり（OI-145〜OI-149・OI-181）、プローブの直し（OI-182）を実装レビューまで終えた。`bin/check-open-items --due M41` は通るが、作者の実機の手順（`deploy/README.md`「作者の手順」1〜6）がまだ流れていないので、M41 は閉じない。実機の手順だけをサイクル 07 へ移した（`inventory.md`）。

### M42 CI のランナーの版を固定し、公開の配置のイメージを arm64 で組み立てる

- 大きさ：コードの変更は小さいが、`publish` の条件を GitHub の上でしか確かめられず、ブランチへの push の確かめに一時の commit とその戻しを 12 個積んだ

## 回し方の改善の提案

`guides/dev-cycle.md` か `guides/cycle-end.md` への変更として書く。機械で止められるものは、再発防止（段階 4）で検査や設定を直すので、ここでは提案だけを書く。

1. **作者に判断を問うときは、1 件ずつ、問題の中身・流用元の作り・答えごとに作るものと見せ場を書いた説明の文書を添え、説明に書く事実（費用・作るもの）はコードで確かめてから書く**（`dev-cycle.md`「1. 計画レビュー」、`cycle-end.md`「5. 台帳の棚卸し」）。想定外 3・4 の予防である
2. **作業中の担当に作者の判断を伝えるときは、伝言ではなく、依頼に書いた受け口のファイルに書き、担当は commit と完了の報告の前にそのファイルを読む**（`dev-cycle.md`「残件の台帳」）。レビュアーの結果をファイルで受け取る規則（サイクル 04）は、サイクル 05・06 で一度も結果を失わなかった。同じ形を担当への伝達にも当てる
3. **RED と壊して落ちる記録を証跡に書くことを、レビュアーを立てる担当が読む手順に置き、機械で確かめる**（`implementation-plan.md`「1 つのマイルストーンの進め方」、`bin/check-open-items --due`）。2 サイクル続いたので、文書だけでは止まらない
4. **計画が外部の基盤の振る舞いを当てにする条件の式は、計画レビューで文書を確かめるだけでなく、最初に push して振る舞いを見る確かめを完了条件の前に置く**。M42 は完了条件で 3 回の push を求めていたので捕まったが、計画の式そのものは文書の記述だけで決めた。1 回だが、CI の配線は push でしか確かめられない種類なので、`guides/config.md`「CI の工程」の「配線を変えた PR は手で確かめる」で足りるかを再発防止で判断する
