# サイクル 06 の知見の収穫

サイクル 06（M42・M43・M44・M45・M46・M41 の残り）の実装で分かったことのうち、正本に無いものを正本へ書いた記録である。手順は `guides/cycle-end.md`「2. 知見の収穫」にある。逸脱検査（`conformance.md`）は、ここで足した正本を含めて成果物と突き合わせる。再発防止（`recurrence.md`）は、ここにある知見を 2 度書かない。

読んだものは、サイクルの diff（`git diff 052a8c1..1358e37`）、振り返りの想定外（`retrospective.md`）、台帳の `judgment` の行（OI-182〜OI-191）と改善の候補（IB-99〜IB-111）、実装レビューの証跡の「実装の記録」、正本（`architecture/`・`adr/`・`guides/`・`README.md`・`showcase.md`・`deploy/README.md`）である。diff の層ごとの読み取りは、取りまとめ役とも実装者とも別の Claude のサブエージェントに `1358e37` の版で頼み、結果をファイルと行で確かめてから書いた。マイルストーンの中で正本に書き足した分（`data-model.md` の品目の写し、`context-map.md` の同期の書き込み、`graphql-schema.md`「ページングと N+1」の並べ替えの列と SDL、`testing.md`「行列テストとの分担」、`config.md`「CI の工程」、`bin.md`「CI が使うもの」、`README.md`「開発環境」、`deploy/README.md`、`adr/009`〜`adr/011`）は済んでいるので、ここではその漏れを拾った。

見せどころ（`showcase.md`）は、サイクル 06 で一度も変わっておらず、M42・M44・M45・M46 のどれも載っていなかった。漏れの中心はここである。
