# サイクル 05 の台帳の棚卸し

サイクル 05（M38・M39・M40・M33・M41）の終わりに、残件と改善の候補の 2 つの台帳を全部読み直した記録である。手順は `guides/cycle-end.md`「5. 台帳の棚卸し」にある。作者への一覧は、サイクル末の PR の本文の冒頭に貼る。

## 作者への一覧

作者の判断が要る `blocked-user` と、作者が不在の間に取りまとめ役が決めた `judgment` である。内容と判断の理由は `plans/open-items.md` の各行にある。作者が最初に読む問いを先に置き、残りを ID の順に並べる。

### 先に決めてほしい問い

1. **公開の配置の値と実機の確かめ（OI-145〜OI-149）**。M41 はこれを待って閉じられず、残りをサイクル 06 へ移した（`retrospective.md`「M33 と M41 を閉じずにサイクル末に入ったこと」）。どれも既定で作ってあり、全部既定でよければ「全部既定で」と答えればよい。OI-147 だけは、Raspberry Pi で `free -h` を流した値と機種が要る。答えの後に、作者が `deploy/README.md`「作者の手順」1〜6 を実機で流し、結果を PR か台帳に書くまで公開しない。説明は `cycle-05/deploy-author-decisions.md` にある
2. **M33 の画面の残り（OI-144・OI-177〜OI-179）**。並べ替えの列を一覧の表に限るか（OI-144）、取消依頼のボタンを出す発注の状況（OI-178）、品番照合待ちを含む受注の合計金額を出すか（OI-179）を決める。どれも既定（いまの画面）で動いている。作者が受け入れのときに後で出すとした画面の細かい指摘は、出たら OI-177 に書いて M33 で直す
3. **リポジトリのライセンス（OI-181）**。public にしたリポジトリに LICENSE を置くか。既定は置かない

## 残件の読み直し

`open` の行を全部読んだ。要らなくなった行は無かった。

| ID | 引当先 | 読み直した結果 |
|---|---|---|
| OI-177 | M33 | 作者の画面の細かい指摘。作者が出すまで残す。M33 の節に書いた |
| OI-180 | M41 | 逸脱検査 D7 の確かめ（`images` のキャッシュが効いた後の時間）。このサイクル末の PR の CI（`39e6111`）で 5 分 0 秒と測れたので、閉じた |

閉じた行は、OI-06（作者が public にした）と OI-180 である。足した行は、OI-177（作者の受け入れ）、OI-178・OI-179（逸脱検査の作者の判断）、OI-180（逸脱検査の要確認）、OI-181（ライセンス）である。引当先を後のマイルストーンにした行は、その節に ID と作業を書いた（M33 に OI-177〜OI-179、M41 に OI-180・OI-181）。計画の M33 と M41 の節の「public にする時期はまだ決めない」という文を、OI-06 の結果に合わせて直した。

`bin/check-open-items --due` を、サイクル 05 のマイルストーンのそれぞれで流した。M38・M39・M40 は通った。M33 は OI-144・OI-177〜OI-179 で、M41 は OI-145〜OI-149・OI-181 で落ちる。どちらも作者を待つ残りで、サイクル 06 へ移した（`guides/dev-cycle.md`「全体の流れ」）。
