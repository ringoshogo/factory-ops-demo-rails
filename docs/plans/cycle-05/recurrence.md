# サイクル 05 の再発防止

サイクル 05（M38・M39・M40・M33・M41）で直し終えた指摘と食い違いの原因をたどり、同じ種類が再び起きない仕組みを足した記録である。手順は `guides/cycle-end.md`「4. 再発防止」にある。直すこと（是正）は各マイルストーンと逸脱検査で済んでいるので、ここでは予防だけを扱う。知見の収穫（`harvest.md`）に書いた知見は、ここに書かない。

読んだものは、実装レビューの指摘（High は M33-R1・M41-R2・M41-R3、Medium と、振り返りで 2 回以上と数えた種類の Low）、逸脱検査の「文書が正」（`conformance.md` の D3・D10・D11）、振り返りの想定外と回し方の改善の提案、サイクル 04 の再発防止（`cycle-04/recurrence.md`）である。指摘は、振り返りの「指摘の数」の種類ごとにまとめ、まとめた行に出どころを挙げた。
