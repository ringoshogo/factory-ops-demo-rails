## 改善の探索の起動判定

`guides/cycle-end.md` の表を上から当てた。判定は、逸脱検査の commit（`2ad9aca`）の後の台帳で行った。

| 台帳の状態 | 当たるか |
|---|---|
| `未着手` が 3 件以上ある | **当たる**（4 件。IB-158・IB-159・IB-160・IB-161） |
| `未着手` が無く、直近 2 サイクルの証跡に `improvement.md` が無い | 当たらない |
| `試行中` があり、判定するマイルストーンを終えた | 当たらない（`試行中` は無い） |
| `起票済み` があり、起こしたマイルストーンを終えた | **当たる**（IB-154・IB-156・IB-157 は M58。IB-130 は判定し直す時機） |

判定：改善の探索を「検証」で回す（`improvement.md`）。裁定の後の `未着手` は 0 件で、`起票済み` も無いので、次のサイクル末は、新しい違和感が 3 件以上積まれるか、`起票済み` が起きない限り起動しない見込みである。
