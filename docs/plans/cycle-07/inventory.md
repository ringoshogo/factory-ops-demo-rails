# サイクル 07 の台帳の棚卸し

サイクル 07（M48・M49・M47・M50・M33 の残り・M41 の残り）の終わりに、残件と改善の候補の 2 つの台帳を全部読み直した記録である。手順は `guides/cycle-end.md`「5. 台帳の棚卸し」にある。作者への一覧は、サイクル末の PR の本文の冒頭に貼る。答えが要る問いと確かめてほしい判断の説明は、1 件ずつ `author-decisions.md` に書いた（`guides/dev-cycle.md`「1. 計画レビュー」）。

## 作者への一覧

作者の判断が要る `blocked-user` と `open` の待ちの行と、作者が不在の間に取りまとめ役が決めた `judgment` である。内容と判断の理由は `plans/open-items.md` の各行にある。作者が最初に読む問いを先に置き、残りを ID の順に並べる。

### 先に決めてほしい問い

どちらも、取りまとめ役のおすすめが既定と違う。説明は `author-decisions.md` の 1・2 にある。

1. **品目の単位の並び順（OI-199、`blocked-user`）**。いまは DB の既定の照合順序で「個 < 本 < 箱」、`ja-x-icu` にすると流用元と同じ「個 < 箱 < 本」。おすすめは `ja-x-icu`（小さい）
2. **CI の `publish` の守りの書き方（OI-184 への追記）**。いまは暗黙の `success()` に頼り、YAML の行に守りが見えない。おすすめは `success()` を明示する形（小さい）

作者が手を動かすことは、公開の配置の実機の手順（OI-196、M41 の残り）と、M33 の画面の細かい指摘（OI-177、M33 の残り。取消済の伝票の明細の行の文言 IB-126 も一緒に）である（`author-decisions.md` の 3・4）。
