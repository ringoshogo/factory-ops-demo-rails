# サイクル 10 の台帳の棚卸し

サイクル 10（M57・M54 の残り・M33 の残り・M41 の残り）の終わりに、残件と改善の候補の 2 つの台帳を全部読み直した記録である。手順は `guides/cycle-end.md`「5. 台帳の棚卸し」にある。作者への一覧は、サイクル末の PR の本文の冒頭に貼る。確かめてほしい判断の説明は、1 件ずつ `author-decisions.md` に書いた（`guides/dev-cycle.md`「1. 計画レビュー」）。

このサイクル末は、改善の探索の起動判定（下の「改善の探索の起動判定」）を逸脱検査の後の台帳で先に決め、改善の探索の調査と裁定を再発防止の後に回し、この記録を改善の探索の裁定の後に書いた。サイクル 08・09 と同じ順である。

## 改善の探索の起動判定

`guides/cycle-end.md` の表を上から当てた。判定は、逸脱検査の commit（`4ff290f`）の後、再発防止の版（`c72052a`）の台帳で行った。再発防止で、表に「`起票済み` があり、起こしたマイルストーンを終えた」の行を足した。

| 台帳の状態 | 当たるか |
|---|---|
| `未着手` が 3 件以上ある | **当たる**（3 件。IB-154・IB-155・IB-156） |
| `未着手` が無く、直近 2 サイクルの証跡に `improvement.md` が無い | 当たらない |
| `試行中` があり、判定するマイルストーンを終えた | 当たらない（`試行中` は無い） |
| `起票済み` があり、起こしたマイルストーンを終えた | **当たる**（IB-144・IB-145・IB-150 は M57、IB-151・IB-152 は M54 の残り。IB-130 は判定し直す時機） |
