# 改善の候補の台帳

いまの設計・実装のやり方より良いやり方がありそうだ、という候補の正本。残件と違い、決着させないと先へ進めないものではないので、引当先を持たない。取りまとめ役は、実装レビューの「違和感」と振り返りの「想定外」をここへ移し、サイクル末にこの台帳の状態で改善の探索を起動するかを決める。運用は `../guides/cycle-end.md`「改善の探索」にある。

新しい候補は、最後の番号の次を振って表の末尾に足す。見送った行も消さない。見送りの理由が残っていれば、同じ候補が再び出たときに、その理由との差分だけを調べればよい。表の形と ID の参照は `bin/check-open-items` が CI で確かめる。

| 状態 | 意味 | 判定の記録に書くこと |
|---|---|---|
| `未着手` | 積んだだけで、まだ調べていない | — |
| `調査中` | 改善の探索で調べている | — |
| `試行中` | 採用し、1 つのマイルストーンで試している | 何をもって効いたとするかと、判定するマイルストーン |
| `反映済み` | 試行が効き、設計文書か `guides/` に反映した | 反映した文書と節 |

| `監視` | 有望だが時期が早い | 何が起きたら調べ直すか |
| `見送り` | 効き目が不明・費用が大きい・いま要らない | 見送った理由 |
