# サイクル 09 の台帳の棚卸し

サイクル 09（M52・M53・M54・M55・M33 の残り・M41 の残り と、サイクル末の M56）の終わりに、残件と改善の候補の 2 つの台帳を全部読み直した記録である。手順は `guides/cycle-end.md`「5. 台帳の棚卸し」にある。作者への一覧は、サイクル末の PR の本文の冒頭に貼る。答えが要る問いと確かめてほしい判断の説明は、1 件ずつ `author-decisions.md` に書いた（`guides/dev-cycle.md`「1. 計画レビュー」）。

このサイクル末は、改善の探索の起動判定（下の「改善の探索の起動判定」）を振り返りの時点の台帳で先に決め、改善の探索の調査と裁定を再発防止の後に回し、この記録を改善の探索の裁定の後に書いた。`guides/cycle-end.md`「流れ」は棚卸しを改善の探索の前に置くので、調査と裁定の版には、この記録と `author-decisions.md` が無かった。サイクル 08 と同じ順である。

## 作者への一覧

作者の判断が要る `blocked-user` と `open` の待ちの行と、作者が不在の間に決めた `judgment` である。内容と判断の理由は `plans/open-items.md` の各行にある。作者が最初に読む問いを先に置き、残りを ID の順に並べる。

### 先に決めてほしい問い（答えで作るものが変わる）

1. **出荷依頼の受注番号の写しを残すか、受注から引く形に替えるか**（OI-226、M54 の残り。`author-decisions.md` の 1）。M54 で出荷が受注に依存したので、写した理由が成り立たない。おすすめは、写しを残して ADR 011 とコメントの理由を書き直す（小さい）
2. **発注の進みの「請求書の受領」を、受注側の発行日のままにするか**（OI-228、M53 の残り。`author-decisions.md` の 2）。おすすめはいまのまま
3. **終えたマイルストーンの計画の節に残る、M54 で消した仕組みを前提にした文に印を付けるか**（OI-223。`author-decisions.md` の 3）。おすすめは、計画の冒頭に注記を 1 段落置く（数行）
