レビュアーに渡したのは、サイクルの diff（`5f67a8e..74b4ceb`。`74b4ceb` は知見の収穫の commit）、正本（知見の収穫で足したものを含む）、サイクルのマイルストーンの節、振り返りの「計画から実装への逆向きの照合」、台帳である。依頼には読む版を `74b4ceb` と書き、作業ツリーを読まないよう求めた（`guides/dev-cycle.md`「依頼の型」）。Codex は `git show` で、Claude は `git archive` で取り出したファイルを読んだ。どちらもテストは流さず、ファイルと行を照らした。

## 違和感

- **出荷取消の受け手が解除する停止**（Claude）：出荷取消の受け手は、承認した審査の停止だけでなく、受注の解除前の停止をすべて解除する。`data-model.md` の受け口の表とも OI-67 とも食い違わないが、表はどの停止を解除するかを書いていない。記録だけにした
- **ページングの規則の文**（Claude）：「ページングと N+1」の「引数は `first`・`after` だけ」は、`customerTenantId`・`itemId` のような親を ID で選ぶ引数とも字面で食い違う。OI-78 の決着と一緒に直す（OI-78 の行に書いた）
