# サイクル 08 の台帳の棚卸し

サイクル 08（M51・M50 の残り・M33 の残り・M41 の残り）の終わりに、残件と改善の候補の 2 つの台帳を全部読み直した記録である。手順は `guides/cycle-end.md`「5. 台帳の棚卸し」にある。作者への一覧は、サイクル末の PR の本文の冒頭に貼る。答えが要る問いと確かめてほしい判断の説明は、1 件ずつ `author-decisions.md` に書いた（`guides/dev-cycle.md`「1. 計画レビュー」）。

このサイクル末は、改善の探索の起動判定（下の「改善の探索の起動判定」）を振り返りの時点の台帳で先に決め、改善の探索の調査を逸脱検査と並べて進め、この記録を改善の探索の裁定の後に書いた。`guides/cycle-end.md`「流れ」は棚卸しを改善の探索の前に置くので、調査と裁定の版には、この記録と `author-decisions.md` が無かった（`improvement.md` の違和感）。
